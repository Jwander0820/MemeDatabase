# 委託 Agent 蒐集新梗圖

選一個能搜尋網頁、開啟來源並看圖的 Agent，複製下方共用提示詞，填入本次的主題或來源網址。第一次可先收 10 張確認方向。續收時附上前次清單；多個 Agent 分工時各給一個主題，最後把清單一起交給整併用的 Agent。只有聊天介面的 Agent 可直接回傳 JSONL 文字。

## 共用提示詞

```text
請依【本次主題或來源網址】蒐集可用於聊天回覆的梗圖。逐一打開來源頁並看清實圖，記下能再次找到該圖的頁面連結。搜尋結果縮圖只作線索。看不到實圖的項目另列待查，並說明原因。

交付一份 UTF-8 JSONL 候選清單，每個不同版本一行。每行包含以下欄位：
- source_page：指向該張圖的貼文或頁面；image_url：可取得的圖片網址，沒有穩定直連就填 null。
- subject：作品或主題；caption：逐字保留圖上台詞或字幕，無字填 null，模糊處不要猜。
- description：用一句繁中描述畫面上可辨認的動作、表情或物件。
- tags：每次打開實圖時就填好 AI 推薦標籤，供審核頁直接預覽與修改。保留任務指定的搜尋詞，再根據這張圖的主體、動作或台詞推薦情緒與回覆情境。無字圖也適用，只填有畫面依據的詞。
- usage：舉一個自然的聊天使用時機；情緒難辨時可填 null。

若提供舊清單，先比對再補新圖。同圖轉貼或單純縮放只留來源最清楚的一筆；同底圖換台詞且改變笑點，可保留兩版並在描述註明差異。若無法比較既有圖庫，回報去重範圍。最後列出新增張數、合併的重複數與待查項目。
```

## 合併多份成果

```text
請合併附件中的既有清單與各 Agent 的新清單。保留既有紀錄，逐張比對來源、畫面與台詞，把同一張圖的轉貼合併，補上遺漏的來源或搜尋詞。確認每筆都保留本批指定的搜尋詞，無字圖的 caption 是 null。交付完整合併版 JSONL，另列新增、補充、重複與待查數量。無法判定是否同圖的項目保留供人工比對。
```

## 與本專案銜接

有專案存取權的 Agent 完成搜尋後，將候選 JSONL 和可直接開啟的 HTML 一起交付。在專案根目錄執行以下指令，替換成當次批次的檔案路徑。若已有核准清單，加上 `--approved 核准清單.jsonl` 可設定首次開頁的勾選。

```powershell
.venv\Scripts\python.exe scripts/build_meme_review.py data/web-meme-import/候選清單.jsonl
```

網路蒐集的候選與核准 JSONL 放在 `data/web-meme-import/`。視覺化審核固定開啟 `data/web-meme-import/review.html`；切換批次前先匯出要保留的核准清單，再用上方指令更新同一頁。多批清單可用主題命名。

每張圖的「圖片出處」填實際找到圖片的貼文或網頁永久連結，保留能辨認該圖的查詢參數。「圖片直連」填媒體網址，缺少時可留空。轉貼頁只能證明找到圖片的位置，原作者需另有依據。兩個網址都隨核准資料匯出。

審核頁預設展開畫面描述與使用時機。上方切到「圖庫預覽」可檢查收錄欄位；兩個模式都能用「編輯收錄欄位」修正內容。儲存會更新本機預覽，匯出時採用修改後的值。管理端的手動新增與編輯頁也提供選填的圖片出處，保存在 `meme_entries.source_page`。

### 將核准清單匯入私人圖庫

搜尋 Agent 提供可讀取的圖片直連與來源頁即可。核准後，由匯入工具下載圖片並驗證格式；一般批次可省去預先下載整批候選的步驟。

```powershell
.venv\Scripts\python.exe -m src.anime_memes import-web-memes data/web-meme-import/approved_memes.jsonl
.venv\Scripts\python.exe -m src.anime_memes import-web-memes data/web-meme-import/approved_memes.jsonl --apply
```

第一行預檢，第二行實際下載歸檔並逐筆寫入。結果按清單行號回報。成功項目保存作品、角色、標題、台詞、標籤及網址；描述與使用時機留在審核檔。失敗項目可修正後重跑，同一圖片直連已由此工具匯入時會跳過。不同網址指向同一張圖時仍需在審核階段去重。

圖片入庫後，可在管理頁明細用人工標籤補上需要的搜尋詞，儲存後搜尋確認。若交給 Agent 標註既有圖片，請照[圖片標籤操作手冊](agent-image-tagging-guide.md)匯出工作並選用 taxonomy 允許的 ID。清單中的自由搜尋詞可供人工補標參考。
