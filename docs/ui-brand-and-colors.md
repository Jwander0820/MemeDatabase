# 品牌圖示與前端色彩規範

- 版本：1.1
- 日期：2026-11-26
- 狀態：品牌圖示（03 版 `M↻E` 四格漫雙生格）、四階濃淡紫主色與深淺色 Token 已套用於公開／管理頁；共用來源為 `web_static/catalog.css`。以下保留色票、對比基準與新增元件的套用規則。

## 1. 品牌圖示設計（03 版：`M↻E` 四格漫雙生格）

### 核心概念

1. **字面雙關（`ME × ME = MEME`）**：以 2×2 四格漫畫（4-koma）排列出上排 `M E`、下排 `M E`，合讀即為 `MEME`，同時呼應模因複製增殖的意象。
2. **幾何旋轉同構（`M ↻ E`）**：圖示中的 `M`（三爪朝下）與 `E`（三爪朝右）採用完全相同的 `12×12` 三叉幾何結構，逆時針旋轉 90° 即由 `M` 變為 `E`。
3. **起承轉合色階**：四格依漫畫閱讀節奏由淺至深遞進（起 → 承 → 轉 → 合），右下角「梗點格」以深夜紫黑反白收尾，確保縮放至 `16×16 px` 瀏覽器分頁 Favicon 時仍具備高辨識度的對角明度反差。

### 檔案位置與使用規則

- 單一來源檔案：`src/anime_memes/web_static/favicon.svg`（`viewBox="0 0 64 64"`）。
- 私人管理頁由 `/static/favicon.svg` 供應；公開搜尋頁與本機 `/browse` 由 `/assets/favicon.svg` 供應（Nginx 映像建置與本機 Flask 共用同一份檔案，不重複維護兩份 SVG）。
- 瀏覽器 Favicon 維持正向不旋轉，確保 `16×16 px` 像素邊緣銳利；頁面頂欄／側欄 `.brand-mark` 套用 `transform: rotate(-4deg)` 保留貼紙手感。

## 3. 無障礙對比度基準（WCAG 2.1）

四個主色彼此搭配時，文字與背景須遵守下列已驗證的高對比組合，避免「中明度紫配白字」或「深紫底配黑字」造成閱讀困難：

| 背景色 | 搭配文字／圖示色 | 對比度 | 等級 | 適用元件 |
|---|---|---|---|---|
| `#2B1854`（`--lilac-900`） | `#F5F0FF`（`--lilac-50`） | **13.8 : 1** | AAA | 淺色模式主按鈕、Active 篩選膠囊 |
| `#DDD0FE`（`--lilac-200`） | `#2B1854`（`--lilac-900`） | **10.7 : 1** | AAA | 深色模式主按鈕、Active 篩選膠囊、淺色次要膠囊 |
| `#B69DF8`（`--lilac-400`） | `#1F1638`（`--lilac-ink`） | **7.5 : 1** | AAA | 強調徽章、深色模式主按鈕 Hover 態 |
| `#B69DF8`（`--lilac-400`） | `#2B1854`（`--lilac-900`） | **6.8 : 1** | AA | 強調標籤、次要提示色塊 |
| `#F5F0FF`（`--lilac-50`） | `#2B1854`（`--lilac-900`） | **13.8 : 1** | AAA | 選中列淡底、資訊提示框 |

## 4. 前端套用規則

### 淺色模式（Light Mode）建議映射

- **背景基底**：維持中性暖紙白／淺灰白為大面積背景，避免整頁鋪滿高彩度紫色造成圖片色彩偏移；以 `--lilac-50`（`#F5F0FF`）作為局部選中卡片、Drawer 標頭或篩選區淡底。
- **主按鈕與選中膠囊（Primary & Active Chip）**：底色使用 `--lilac-900`（`#2B1854`），文字使用 `--lilac-50`（`#F5F0FF`）；Hover 態可略提亮至 `#3B2370`。
- **一般標籤膠囊（Tag Chip）**：未選中維持低干擾中性底，Hover 時邊框轉為 `--lilac-400`（`#B69DF8`）、底色轉為 `--lilac-50`（`#F5F0FF`）。
- **鍵盤焦點（`:focus-visible`）**：統一使用 `2px solid var(--lilac-400)`（`#B69DF8`）或深紫對比框，確保鍵盤導覽清晰。

### 深色模式（Dark Mode）建議映射

- **背景基底**：維持深炭黑（`#0F0F11`～`#18181B`）以凸顯梗圖本身色彩，不將全頁背景改為亮紫。
- **主按鈕與選中膠囊（Primary & Active Chip）**：使用 `--lilac-200`（`#DDD0FE`），Hover 態使用 `--lilac-400`（`#B69DF8`），文字使用 `--lilac-900`（`#2B1854`）。黃色僅保留收藏等功能語意用途。
- **連結與次要強調**：文字連結與選中邊框使用 `--lilac-200`（`#DDD0FE`）或 `--lilac-400`（`#B69DF8`），確保在 `#18181B` 卡片底上對比度大於 `7:1`。
- **深色品牌區塊**：需要區隔管理狀態列或特殊橫幅時，可使用 `--lilac-900`（`#2B1854`）搭配 `--lilac-200` 邊框與 `--lilac-50` 文字。

### 功能語意色保留原則

- **危險／永久刪除（Danger）**、**成功狀態（Success）** 與 **收藏星號（Favorite 金色 `#E0A800`）** 屬於直覺功能語意色，應維持獨立紅／綠／金色系，不混用紫色，以免降低誤刪警示與收藏辨識度。

## 5. 自訂配色指引

想拿這個專案建立自己的資料庫、換成自己的品牌色時，照本章操作即可；不需要動 HTML 或 JavaScript 邏輯。

### 色彩變數在哪裡

所有顏色集中在 `src/anime_memes/web_static/catalog.css`（公開頁與管理頁共用），分兩個區塊：

- `:root`：淺色主題，同時放兩主題共用的變數（品牌色階、收藏黃、疊在圖片上的顏色、檢視器舞台）。
- `:root[data-theme="dark"]`：深色主題，只覆寫與淺色不同的變數。

`public_ui/theme-init.js` 會在首次繪製前一律於 `<html>` 設定 `data-theme`（使用者選擇優先，否則依系統偏好），並以 `data-theme-source` 區分 `user`／`system`。因此深色變數只需要維護一份。

| 類別 | 變數 | 用途 |
| --- | --- | --- |
| 背景 | `--bg`、`--media-bg`、`--scrim` | 頁面底色、圖片佔位底、對話框遮罩 |
| 表面 | `--surface`、`--surface-2`、`--surface-3`、`--chip`、`--seg-*` | 卡片、輸入框、標籤、分段切換 |
| 文字 | `--ink`、`--ink-2`、`--muted`、`--link` | 主文字、次要文字、輔助說明、連結 |
| 線條 | `--line`、`--line-strong`、`--card-line*`、`--shadow-*` | 分隔線、邊框、陰影 |
| 品牌 | `--lilac-*`、`--brand`、`--brand-ink` | 品牌色階與品牌色塊（徽章、標示） |
| 主色 | `--primary`、`--primary-ink`、`--primary-hover`、`--focus`、`--chip-active*`、`--chip-hover-*` | 主要按鈕、選取狀態、焦點框 |
| 狀態 | `--danger*`、`--success`、`--success-solid`、`--warn-*` | 錯誤、成功、警告 |
| 收藏與圖片疊字 | `--star`、`--star-bright`、`--on-media`、`--on-media-inverse`、`--media-overlay*`、`--media-badge-*`、`--on-primary-soft` | 收藏星號、圖片上的圓鈕與徽章（兩主題相同） |
| 檢視器舞台 | `--stage`、`--stage-text`、`--stage-ink`、`--stage-control-*` | 大圖檢視器的深色背景、說明文字與控制鈕 |

### 換成自己的品牌色

1. 改 `:root` 的 `--lilac-50/100/200/400/900/ink` 色階（或直接改 `--brand`、`--brand-ink`）。
2. 改主操作色：`--primary`、`--primary-ink`、`--primary-hover`、`--focus`、`--link`，淺色與深色兩個區塊都要一起改（深色通常用較淺的色階）。
3. 深色主題的 `--chip-hover-*`、`--chip-active*` 也引用色階，換色後確認仍協調。
4. 檢查對比：用瀏覽器開發者工具或線上對比工具，一般文字對比至少 4.5:1，焦點框與按鈕邊界至少 3:1。
5. 若 `--bg` 改了，不必另外改 meta：`theme-init.js` 會讀取 CSS 的 `--bg` 設定 `meta theme-color`。HTML 內 `meta theme-color` 的初始色碼只是無腳本時的備援，建議一併改成相同值。

### 改完如何檢查

- 公開頁與管理頁都開，淺色與深色各看一次（切換按鈕，或改系統主題）。
- 手機寬度（約 375px）檢查卡片、檢視器、標籤列。
- 圖示 `favicon.svg` 內若寫有品牌色，需另外修改（見第 1 節）。

### 注意事項

- 公開與私人 Nginx 的 CSP 為 `style-src 'self'`，不允許 inline style；所有顏色只能寫在 CSS 檔。
- 不要在其他 CSS 規則裡直接寫色碼，請新增或沿用語意變數。唯一保留寫死的是 `mask-image` 的 `#000`（只當遮罩透明度，不是可見顏色）與少數黑色陰影。
- 沒有 JavaScript 時不會有 `data-theme`，頁面為淺色；僅 `color-scheme` 會跟隨系統。
