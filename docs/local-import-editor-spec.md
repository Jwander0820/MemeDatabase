# 本機圖片匯入與管理頁編輯規格

適用於 `import-web-memes` 與私人管理頁。以這份規格驗收重跑匯入、編輯草稿、整筆儲存及搜尋排序。

## 1. 同一張本機圖片重跑匯入

- 清單只有 `local_path` 時，依通過圖片驗證的原始檔案位元組計算 SHA-256。相同內容即使改名、移動或出現在另一份清單，也只收錄一次。同檔名換成不同內容可再收錄。重新壓縮產生不同位元組會視為另一個檔案。
- 管理庫第 4 版在條目保存 `local_import_sha256`，由唯一索引處理同時匯入。同批重複、跨批重複及另一個程序剛成功匯入的相同檔案都回報 `duplicate`。有 `image_url` 的列沿用網址去重。
- 預檢會讀圖並比對既有紀錄，回報 `ready` 或 `duplicate`；同批第一次可匯入的圖也參與後續列的比對。預檢以唯讀方式使用既有資料庫，資料庫尚未建立時也能執行。
- 舊版收錄的本機圖片沒有指紋。匯入器依舊版產生的附件檔名辨識可能的條目，讀取現存原檔進行比對。原檔遺失時無法核對舊圖內容。已存在的重複條目保留，由使用者決定如何整理。
- **驗收**：匯入一張圖，再以不同檔名預檢並正式匯入相同內容，兩次都應為 `duplicate`，庫內仍只有一筆，附件與縮圖數量維持原值。

## 2. 關閉基本資料草稿

開啟詳情後記錄編輯表單的初始值。梗圖名稱、作品、角色、台詞、出處、替代詞、標籤、狀態或備註有變更時，按 Esc、點背景、點關閉鈕，或切換上一張／下一張，均須先確認放棄修改。標籤框已輸入但尚未按 Enter 的文字也算草稿。此保護適用詳情編輯；手動新增表單目前僅避免帶草稿時點背景誤關，Esc、取消與關閉鈕仍會放棄新增草稿。

**驗收**：取消時仍停在原圖，輸入內容可繼續編輯。確認後才執行關閉或切換。欄位改回初始值、或成功儲存後直接關閉，均不應再出現確認。

## 3. 基本資料與完整標籤整筆儲存

管理頁一次送出 `PATCH /api/entries/<key>`。基本資料、`display_title`、`search_aliases` 與 `tags` 共用一個 SQLite 交易。欄位省略即保留原值；空替代詞陣列、空標籤清單可分別清除對應資料。標籤欄代表完整正式標籤集合：保留的標籤維持原來源，新加入的標籤記為 `manual`；移除的標籤不論來源均刪除。未接受的候選另行審核，不因儲存表單自動接受。既有單獨編輯標籤的 `PUT /api/entries/<key>/tags` 使用相同規則。

**驗收**：一次修改名稱、替代詞及標籤，重新讀取能看到三者。再次送出含無效標籤格式的修改，API 回傳 400，重新讀取仍是上一次成功儲存的內容。前端保留失敗的草稿，供使用者修正重送。

## 4. 搜尋名稱、替代詞與排序

管理詳情可編輯「梗圖名稱」與「也可以這樣搜」。替代詞每行一筆，略過空行，保留詞內空格。後端沿用每筆最多 200 字、每張最多 50 筆及正規化去重規則。

管理列表預設選「自動」，無查詢詞按最近更新，有查詢詞按相關度。手動選擇最近更新、最近新增、來源時間、作品、隨機或相關度後，修改查詢詞與載入下一頁都沿用該選擇。選回自動即恢復上述預設。

**驗收**：在詳情新增一行含空格的替代詞，儲存後可搜尋到原圖。手動改為最近更新後繼續搜尋，排序仍是最近更新。
